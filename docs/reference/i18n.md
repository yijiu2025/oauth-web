# 国际化

vue-i18n，简体中文（`zh_cn`）默认，英文（`en`）兜底。

## 一、装配层 `src/i18n/index.ts`

装配层**只做装配，不放任何文案**：

```ts
const i18n = createI18n({
  legacy: false,
  locale: 'zh_cn',
  fallbackLocale: 'en',
  messages: {
    zh_cn: { login: login.zh_cn, auth: auth.zh_cn, /* … */ },
    en: { login: login.en, auth: auth.en, /* … */ }
  }
});
```

## 二、领域文件组织

一个领域 = 一个文件，文件名即 namespace（key 前缀）：

| 文件 | 领域 |
| --- | --- |
| `login.ts` | 登录页文案 |
| `register.ts` | 注册页文案 |
| `forgot.ts` | 找回 / 重置密码文案 |
| `auth.ts` | 授权相关文案 |
| `validation.ts` | 表单校验提示 |
| `not_found.ts` | 404 文案 |
| `app_missing.ts` | 缺 app 上下文文案 |

每个领域文件双语（`zh_cn` / `en`）收在一起，`en` 用 `Record<keyof typeof zh, string>` 强制与
`zh` 的 key 对齐——**漏译 / 多译编译报错**。

## 三、新增语言 / 领域

- **新增领域**：新建一个领域文件 + 在 `messages` 的 zh_cn / en 两处各注册一行，不要往装配层塞文案；
- **新增语言**：为每个领域文件补一个语言对象 + 在 `messages` 加一个语言块。
